## What I build

I craft production-ready, fully containerized full-stack applications — from the Nginx reverse proxy and SSL pipeline down to the Vue component and Electron window chrome. If it ships across web, mobile, and desktop from a single codebase, that's my kind of project.

My portfolio at [baderidris.com](https://baderidris.com) is a live, SEO-optimized SSR application running on my own server — not a demo, not Vercel, not a placeholder. It's built on Nuxt 4 with real-time Socket.io, dual-database (MongoDB + PostgreSQL via Prisma), Redis caching, a self-hosted Postfix/Dovecot mail stack, Certbot SSL, Fail2Ban DDoS protection, and CI/CD — simultaneously distributed as a web app, Android/iOS app (Capacitor), and desktop app (Electron + Electrobun), all orchestrated by Docker Compose.

## Flagship project — nuxt4-fullstack-portfolio

[![Stars](https://img.shields.io/github/stars/Bader-Idris/nuxt4-fullstack-portfolio?style=flat-square&color=6366F1)](https://github.com/Bader-Idris/nuxt4-fullstack-portfolio/stargazers)
[![Forks](https://img.shields.io/github/forks/Bader-Idris/nuxt4-fullstack-portfolio?style=flat-square&color=6366F1)](https://github.com/Bader-Idris/nuxt4-fullstack-portfolio/forks)
[![Latest Tag](https://img.shields.io/github/v/tag/Bader-Idris/nuxt4-fullstack-portfolio?style=flat-square&color=22c55e)](https://github.com/Bader-Idris/nuxt4-fullstack-portfolio/releases)
[![License](https://img.shields.io/github/license/Bader-Idris/nuxt4-fullstack-portfolio?style=flat-square)](https://github.com/Bader-Idris/nuxt4-fullstack-portfolio/blob/bader/LICENSE)

A production-ready, self-hosted full-stack portfolio **running live** at [baderidris.com](https://baderidris.com) — SEO-optimized SSR on my own server, not a cloud deployment. The same codebase ships as:

| Platform | Distribution |
|---|---|
| 🌐 Web (SSR + SSG) | Nuxt 4 via Nginx + Docker on self-hosted VPS |
| 📱 Android & iOS | Capacitor.js — [tagged releases →](https://github.com/Bader-Idris/nuxt4-fullstack-portfolio/releases) |
| 🖥️ Desktop (Win / macOS / Linux) | Electron + Electrobun — [tagged releases →](https://github.com/Bader-Idris/nuxt4-fullstack-portfolio/releases) |

**Infrastructure highlights:**
- Containerized with Docker Compose — separate dev, prod-test, and certbot pipelines
- Self-hosted email (Postfix + Dovecot) with SMTP auth
- Auto-renewing SSL via Certbot + Nginx reverse proxy
- Fail2Ban custom jails for DDoS mitigation
- Pre-built image on [Docker Hub](https://hub.docker.com/r/baderidris/nuxt-portfolio) for low-resource server deployments
- MongoDB 4 → 8 migration guide included
- GitHub Actions CI/CD + multi-language README (EN / AR / ES)
